## درباره پروژه

**v2Eleven** یک کلاینت اندرویدی سفارشی بر پایه پروژه متن‌باز [v2rayNG](https://github.com/2dust/v2rayNG) است. هدف، حفظ هسته شبکه و پشتیبانی پروتکل‌های پروژه اصلی و ارائه تجربه‌ای ساده‌تر با هویت بصری Eleven است.

### مسیرهای اصلی

- اشتراک (Subscription)
- گیمینگ ترکیه (Turkey Gaming)
- وب‌گردی (Web Browsing)
- وارد کردن لینک اشتراک و دسته‌بندی سرورها بر اساس پرچم ترکیه یا نام کشور
- نمایش حجم مصرفی و تاریخ انقضا، در صورت ارائه این اطلاعات از طرف سرویس اشتراک
- لینک تمدید و پشتیبانی:
  - تمدید: [ElevenPing](https://t.me/ElevenPing)
  - پشتیبانی: [ElevenJT](https://t.me/ElevenJT)

### وضعیت پروژه

این پروژه در حال توسعه است. فایل‌های نصب رسمی باید از بخش **Releases** دریافت شوند؛ بیلدهای GitHub Actions برای آزمایش هستند.

### مجوز و پروژه اصلی

پروژه اصلی [2dust/v2rayNG](https://github.com/2dust/v2rayNG) تحت مجوز GPL-3.0 منتشر شده است. هنگام تغییر یا توزیع برنامه، اعلان‌های حق نشر، فایل‌های مجوز و تعهدات مربوط به انتشار کد منبع باید حفظ شوند.

نام برنامه و شناسه بسته موردنظر: `v2Eleven` و `ir.armaneleven.v2eleven`.

## English

**v2Eleven** is a custom Android client based on the open-source [v2rayNG](https://github.com/2dust/v2rayNG) project. It aims to preserve the upstream networking engine and protocol support while introducing a focused experience and Eleven visual identity.

### Download

- **[Download the latest stable release](https://github.com/ArmanEleven/V2Eleven/releases/latest)**
- **[Browse all releases](https://github.com/ArmanEleven/V2Eleven/releases)**
- [Preview APK builds on GitHub Actions](https://github.com/ArmanEleven/V2Eleven/actions/workflows/build-apk.yml)

> If no release has been published yet, the stable-download link will not contain an installable APK. GitHub Actions artifacts are for testing and may expire.

### Main destinations

- Subscription
- Turkey Gaming
- Web Browsing
- Import a subscription URL and categorize servers by Turkey flag or country name
- Display traffic usage and expiry when provided by the subscription service
- Renewal: [ElevenPing](https://t.me/ElevenPing)
- Support: [ElevenJT](https://t.me/ElevenJT)

### Project status

The project is under active development. Use the **Releases** page for official installable builds; GitHub Actions builds are intended for testing.
