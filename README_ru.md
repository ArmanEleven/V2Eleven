# V2 Eleven

V2 Eleven — Android VPN-клиент с открытым исходным кодом на базе Xray-core, с отдельными интерфейсами для смартфонов и Android TV.

## Возможности

- VLESS, VMess, Shadowsocks, Trojan и Hysteria2
- Подписки с автоматическим обновлением
- Импорт конфигураций через QR-код
- Передача конфигурации с телефона на Android TV
- Отдельный интерфейс Android TV с навигацией через пульт
- Маршрутизация и split tunneling для приложений
- Тестирование соединения и проверка IP
- Локальный сервер конфигурации
- Локальное хранение профилей через Room
- Автоматическое обновление geo-баз

## Требования

- Android 7.0+ (API 24)
- Android Studio с актуальным Android Gradle Plugin
- Xray core через встроенный `libv2ray.aar`

## Сборка

    git clone https://github.com/ArmanEleven/V2Eleven.git
    cd V2Eleven
    ./gradlew assembleDebug

Debug APK будет создан в:

`app/build/outputs/apk/debug/app-debug.apk`
